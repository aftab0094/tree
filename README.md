# Tree

### Install

`git clone https://github.com/aftab0094/tree`

You can have it in path or env yourself or add a alias

### Features

- Shows all the file and folders in current directory
- did not use AI
- can copy by just type "y"
- works

## example
```
Makefile
SomeFolder --- Hey.txt
               girl_dir
               howudoing.cc

Do you want to copy this to clipboard?(y/n)
```
